# Especificações

Cada issue entregue pela esteira de agentes gera um arquivo `<número>-<slug>.md` aqui, contendo:
requisitos e critérios de aceite (requirements-analyst), plano técnico (architect) e evidências de teste (test-engineer).

Estes arquivos são a memória do projeto: os agentes leem as specs anteriores para manter consistência.
